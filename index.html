How it works

Four steps, no toolchain

1. Pick an application

Wi-Fi bridge, Bluetooth SPP, Bluetooth LE, USB host, serial passthrough, hybrid or the Raspberry Pi CUPS bridge.

2. Pick your board

15 boards from ESP8266 modules to the Raspberry Pi 5 - and you can import your own board JSON at any time.

3. Follow the wiring

A generated diagram, a pin-by-pin table, a bill of materials, safety warnings and a downloadable guide.

4. Flash & configure

Flash from the browser with Web Serial, or run the Raspberry Pi one-liner. Then set up Wi-Fi from the device's own web app.

What the device serves to your browser

Wireless configuration

  • Captive portal + first-run wizard
  • Stores 5 Wi-Fi networks and always reconnects to the last working one
  • Change the AP name, password and static IP
  • Personalise device name, owner and location
  • Raw TCP 9100, mDNS arsin_print_server.local

Label designer

  • Label and receipt presets in millimetres, 203/300 dpi
  • Text, logo upload, lines, boxes and variables like {{serial}}
  • 8 barcode symbologies + QR, Data Matrix and PDF417 output
  • Native commands for ESC/POS, ZPL, TSPL, EPL, CPCL, Star
  • Raster fallback that prints on any printer that accepts graphics

Maintenance & troubleshooting

  • Self test page, status query, configuration dump
  • Media calibration, gap/black-mark sensor test
  • Nozzle check, print-head cleaning routines
  • Counter read/reset, darkness, speed, media type
  • Raw hex console, live log, USB and serial diagnostics
Enterprise ready

Extras that make it deployable

Operations

OTA updates, configuration backup/restore, API keys, webhooks on job completion, job history, byte counters, live SSE status stream, remote reboot and factory reset.

Compatibility

10 printer command languages, ESC/P for dot matrix and inkjets, CUPS + AirPrint on Raspberry Pi for printers that need a real driver.

Fleet

mDNS discovery, predictable hostnames, one JSON config per device, identical REST API on ESP32, ESP8266 and Raspberry Pi.

Browser support: flashing uses the Web Serial API, available in Chrome, Edge, Opera and other Chromium browsers on desktop (Windows, macOS, Linux, ChromeOS). Raspberry Pi images are written with Raspberry Pi Imager and then configured with a single command.
